# Disclaimer

Arwen is an early-access build for invited testers.

Arwen reads the files Elite Dangerous writes to your Saved Games folder (the journal and the status
files). It never changes them and never sends keys to the game. Searches for stations, prices and
materials go to the public Spansh, Ardent and EDSM services; only the system and item you search for
are sent.

of Frontier Developments plc. Use Arwen at your own risk; it is provided as is.
